# Independent applications

**Status: no independent application published here yet.** This directory is reserved for future work. Course banking, weather and GUI exercises belong in `course/`, even if they are called projects in the tutorial.

Create a project here, or link to a dedicated repository, when you have chosen a problem and built a working implementation. Include:

- The user problem and the decisions you personally made.
- Exact setup and run instructions, with dependencies and safe example configuration.
- A screenshot or short demo and an example input/output.
- Meaningful checks, known limitations and source/AI assistance attribution.
- For AI applications: a small evaluation dataset, results and failure analysis; measured latency/cost when applicable.

Then add a direct link and a concise evidence-based description to the root README. Report only measurements actually collected. Keep future ideas outside the completed-project list.
